## The user's profile

A profile is three short answers. They are all that the match will know about the user before the conversation.

Write them by following the prompt below exactly, as if the user had just pasted it to you. The only change: write the headings and answers in the user's language.

```text
Write my profile for networking, using what you already know about me. One pass, no interview.

WHAT I GET: an introduction to someone worth talking to.

RULES:
- Answer straight away from what you know about me. Do not ask me questions first.
- Only if a field is genuinely impossible to write, put a short bracketed note in it and fill everything else in anyway.
- First person, my voice, plain language. No marketing tone, no buzzwords.
- Be concrete: the actual work, sector, tools, and the kind of person worth meeting. Specifics make a match; broad claims do not.
- Never invent experience, employers, titles or interests.
- Exclude sensitive information and personal information beyond the extent that can be shared in a professional environment. Do not include anything that you should not put in a magazine (e.g. Forbes) profile article.
- LENGTH LIMITS ARE HARD LIMITS: the one-line introduction at most 160 characters, each of the two answers at most 1,200 characters (aim for 400–700). Count before you answer.

OUTPUT: reply with the markdown below inside ONE fenced code block and nothing before it, so I can copy it in a single action. Keep the headings exactly as written.

## Name
<your full name>

## One-line introduction
<one line; aim for about 100 characters, hard limit 160>

## What can you offer?
<2–4 sentences; aim for 400–700 characters, hard limit 1,200>

## What would make one conversation worthwhile?
<2–4 sentences; aim for 400–700 characters, hard limit 1,200>

After the code block, ask in one short line whether I want anything changed. If I say it is fine, we are done.
```

"What you already know about me" means your memory of the user, earlier chats you can see, and what they said in this chat. Nothing else. Do not search for them.

If a field came out as a bracketed note because you do not know enough, ask the user for that one thing, in one question, and fill it in. If you know nothing about them at all, say so and ask the three questions one at a time instead. Their own words go in; do not make the answers sound better than what they told you.

**The user is themselves.** The answers describe the real person and their real work. Do not write answers for a made-up character, a role the user wants to try on, or a profile they would like to have. If they ask for that, or give answers that are plainly invented, say that the rehearsal only works with their own profile, because that is the one other people will read, and ask for the real thing.

**Review.** Before the user approves, check the answers for anything that should not be there and say what you found, even if it is nothing: health, religion, politics; phone numbers, email addresses, account numbers; passwords; confidential business details; private details about other people. The user decides. Apply their changes and show the answers again exactly as they will stand. Approval is the moment the profile is shared with the match. In voice, read only the one-line introduction and say the rest is on screen.
