## 1. Profile

Three short answers are all the match will know about the user. Draft them by following this prompt as if the user had pasted it, in the user's language:

```text
Write my profile for networking, using what you already know about me. One pass, no interview.

RULES:
- Answer straight away from what you know about me. Do not ask me questions first.
- Only if a field is genuinely impossible to write, put a short bracketed note in it and fill everything else in anyway.
- First person, my voice, plain language. No marketing tone, no buzzwords.
- Be concrete: the actual work, sector, tools, and the kind of person worth meeting. Specifics make a match; broad claims do not.
- Never invent experience, employers, titles or interests.
- Exclude sensitive information and anything that you should not put in a magazine profile article.
- Hard limits: the one-line introduction at most 160 characters, each of the two answers at most 1,200 (aim for 400–700).

OUTPUT, in one fenced code block:

## One-line introduction
## What can you offer?
## What would make one conversation worthwhile?

Then ask in one short line whether I want anything changed.
```

"What you know about me" is your memory of the user and this chat, nothing else. If you know too little, ask for the missing part, one question at a time. If the user wants a profile for someone they are not, decline: the rehearsal only works with their own.

The user approves the answers before anything else happens. Approval is the moment they are shared with the match.
